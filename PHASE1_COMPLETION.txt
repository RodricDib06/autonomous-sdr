💡 HOW TO USE PHASE 1 FEATURES
═══════════════════════════════════════════════════════════════════════════════

1. EMAIL VALIDATION
   ─────────────────
   Test corporate email:
   $ curl "http://localhost:8000/validate/email?email=john@company.com"
   
   Test temporary email (will be flagged):
   $ curl "http://localhost:8000/validate/email?email=test@tempmail.com"
   
   Batch validate:
   $ curl -X POST -H "Content-Type: application/json" \
     -d '{"emails":["john@company.com","test@gmail.com"]}' \
     http://localhost:8000/validate/email-batch

2. CSV BULK IMPORT
   ───────────────
   Prepare CSV file (sample_leads.csv included):
   name,email,company,source
   John Smith,john@company.com,Acme Inc,linkedin
   
   Import file:
   $ curl -X POST -F "file=@sample_leads.csv" \
     http://localhost:8000/leads/import-csv
   
   Check status:
   $ curl http://localhost:8000/leads/stats

3. DEDUPLICATION
   ──────────────
   Check if a lead has duplicates:
   $ curl http://localhost:8000/leads/abc123/check-duplicate
   
   Get full duplicate report:
   $ curl http://localhost:8000/leads/duplicates/report | jq
   
   Merge duplicates:
   $ curl -X POST http://localhost:8000/leads/primary_id/merge/duplicate_id

4. SLACK ALERTS
   ────────────
   Configure webhook:
   $ curl -X POST \
     "http://localhost:8000/config/slack?webhook_url=https://hooks.slack.com/services/YOUR/WEBHOOK"
   
   Test webhook:
   $ curl -X POST http://localhost:8000/config/slack/test
   
   Disable notifications:
   $ curl -X POST http://localhost:8000/config/slack/disable
